# Acceptance Matrix

The project brief's acceptance tests, T01 to T10, and its seventeen
requirements, RF-01 to RF-10 and RN-01 to RN-07, each with what was run,
the result expected, the result observed and the evidence (work item 62).
The observations come from three places:

- the test suite in a clean clone at the configured location, from the
  reconstruction check of work item 63 on 2026-10-05 at release 0.12.0
  ([development.md](development.md#reconstruction-and-restart)): 1,656
  passed, 5 skipped, none failed;
- the real-data checks of the development case sets, each named where it
  is used;
- the final evaluation of release 0.11.2 ([final-figures.md](final-figures.md)).

The brief sets no numerical threshold and no required improvement over
the baseline. A test is met when its tests pass and what it observes is
what was expected. A limit found is named beside it, and nothing that
fails is marked met.
